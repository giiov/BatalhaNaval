## Batalha Naval
📝 Sobre o Projeto

Este é um projeto básico desenvolvido para a disciplina de Interfaces Web.
O objetivo do trabalho era praticar HTML, CSS, JavaScript, manipulação do DOM e construção de interfaces simples e funcionais.
O jogo simula uma versão leve e divertida de Batalha Naval, com tabuleiro 10x10 e pontuação dinâmica.

# 🚀 Tecnologias Utilizadas
- HTML
- CSS
- JavaScript

## 🎮 Como Jogar
# 🎯 Objetivo

- Acumular 50 pontos para vencer.
- Você começa com 4 vidas.
  
| Elemento | Representação | Pontos |
|---------|----------------|---------|
| s1 | Navio grande | +15 |
| s2 | Navio médio | +10 |
| s3 | Navio pequeno | +5 |
| w  | Água | 0 |
| b  | Bomba | -20 e -1 vida |


- Vidas chegam a 0 → derrota.
- Pontuação ≥ 50 → vitória.
